1. Parámetros de prueba específicos para el Ejercicio C:
   - MedInc: 5.5 (55,000 $ de ingreso medio)
   - AveRooms: 6.0 (habitaciones medias por vivienda)
   - Variables censales por defecto: HouseAge=29.0, AveBedrms=1.05, Population=1166.0, AveOccup=2.8, Latitude=34.26, Longitude=-118.49

2. Valor crudo devuelto por la API FastAPI (/predict):
   MedHouseVal: 2.668796117647059 (expresado en cientos de miles de dólares)

3. Lógica de transformación aplicada:
   precio = med_house_val * 100_000
   precio_formateado = f"${precio:,.0f}"
   Cálculo: 2.668796117647059 × 100.000 = 266.879,61... $

4. Resultado legible en dólares mostrado en Streamlit:
   $266,880

En la interfaz de usuario se muestra la métrica principal con el valor formateado "$266,880" y un texto secundario (caption) con el valor crudo "2.668796117647059" para trazabilidad y verificación.
